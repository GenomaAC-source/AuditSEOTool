### Top 5 Critical Issues

1. **Autoptimize inlines ~1.5 MB of CSS into every page** -- HTML payloads are 90-94% pure CSS, catastrophically harming all Core Web Vitals. Estimated mobile LCP: 5-8 seconds (POOR).
2. **Systemic thin content across the site** -- 7 of 9 pages analyzed fall below content minimums. Blog posts average 300-500 words against a 1,500-word recommended minimum.
3. **Hero images lazy-loaded via JavaScript** -- The LCP element uses `data-src` with a 1px transparent GIF in `src`, defeating the browser's preload scanner and adding 2-4 seconds to LCP.
4. **H1 tags are hidden (visibility: false) on 3 of 4 key pages** -- Only the homepage H1 renders visibly. Hidden H1s are an SEO anti-pattern.
5. **Base font size is 11px** -- Below Google's 16px minimum for mobile readability, causing mobile usability failures.

### Top 5 Quick Wins

1. **Uncheck "Inline all CSS" in Autoptimize** -- Single config change, reduces HTML from ~1.6 MB to ~200 KB per page.
2. **Enable BreadcrumbList schema in Rank Math** -- Single toggle, adds structured breadcrumb markup to all pages.
3. **Change max-image-preview from "standard" to "large"** -- Rank Math setting, enables Google Discover eligibility for all content.
4. **Fix mixed content: update WordPress Site Address to HTTPS** -- Fixes 181 HTTP image references in sitemaps and Organization schema.
5. **Increase base font size to 16px** -- CSS change, fixes mobile readability for entire site.
